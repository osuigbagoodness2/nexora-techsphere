RENDER HOSTING
1. Extract this folder from the ZIP file.
2. Create a new GitHub repository. Upload the contents of this folder to the repository root: index.html, the assets folder, render.yaml and this README.
3. In Render, choose New > Static Site and connect your GitHub repository.
4. If Render asks for settings, use Publish Directory: . (the repository root). The build command can be left blank for this plain HTML website.
5. Click Create Static Site and wait for deployment. Render will provide your live .onrender.com link. You can later connect your own domain in the site's Settings.

The included render.yaml is also suitable for a Render Blueprint deployment if it is placed in the repository root.

This responsive storefront includes sample listings, search, category browsing, sorting and a WhatsApp enquiry shortlist. Keep the assets folder beside index.html so the logo loads.

Product photos and listings are samples. Before publishing, replace them with your own product photos and names, and confirm usage rights. Add your real prices, stock and delivery information. This version is a hosted catalogue with WhatsApp enquiries; it does not process card payments or create paid orders. For full checkout, connect a commerce platform or payment/order service.
